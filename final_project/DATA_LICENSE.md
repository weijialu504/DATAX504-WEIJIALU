# Data source and licence

The unchanged HAR70+ archive included in this package is attributed to:

Logacjov, A., & Ustad, A. (2023). HAR70+ [Data set].
UCI Machine Learning Repository. https://doi.org/10.24432/C5CW3D

Dataset page: https://archive.ics.uci.edu/dataset/780/har70

UCI lists the data under Creative Commons Attribution 4.0 International (CC BY 4.0):
https://creativecommons.org/licenses/by/4.0/

The original archive has not been modified. This project creates derived,
normalised windows for four selected activities. Model outputs are a new analysis,
not results claimed by the original dataset creators.
